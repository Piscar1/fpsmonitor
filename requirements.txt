# CSV-логирование использует встроенный модуль csv (не требует сторонних пакетов).
#
# Измерение реального FPS игр выполняется через PresentMon (Intel GameTechDev).
# Бинарник PresentMon-1.10.0-x64.exe лежит в папке bin/ и не ставится через pip.
# Для работы FPS программу нужно запускать от имени администратора.
#
# GPU (загрузка/температура/частоты/VRAM) читается через NVML (nvidia-ml-py).
# Температуры CPU/платы — через LibreHardwareMonitor (pythonnet + DLL в bin/:
# LibreHardwareMonitorLib.dll, HidSharp.dll и 4 System.*.dll). Требует драйвер
# Ring0, который на части систем заблокирован Windows — тогда CPU-температуры
# недоступны, и карточки автоматически скрываются.
#
# Новые функции в улучшенной версии:
# - 1% low и 0.1% low FPS
# - Frametime (мс) с графиком и историей
# - 6 цветовых тем оверлея (default, dark_blue, cyberpunk, nordic, solarized, matrix)
# - Прогресс-бары в оверлее (3 стиля: закруглённые, квадратные, тонкие)
# - Градиентный фон и рамка оверлея с настраиваемой непрозрачностью
# - Заливка под графиком FPS
# - Отдельный график Frametime
# - Настраиваемые пороги температур (warn/crit) для CPU и GPU
# - CSV-логирование всех метрик в файлы (папка logs/)
# - Динамическая иконка в трее с текущим FPS
# - Имя активного приложения в оверлее
# - Сглаживание линий графика
# - Управление сеткой графика (X/Y)
# - Легенда графика (вкл/выкл)
